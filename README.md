# Python Utilities Project

This project contains utility functions for generating geometric progressions, implementing bubble sort, and searching for keywords in a paragraph.

## Structure
- `math_ops/`: Math related functions.
- `sorting/`: Sorting algorithms.
- `text_tools/`: Text manipulation and search tools.
- `utils/`: Common utilities like logging.

## Error Handling & Logging
Robust error handling is implemented across all functions. Logs are generated in the `logs/` directory.
